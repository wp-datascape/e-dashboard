Dashboard ini bisa dipasang sebagai aplikasi di komputer maupun HP, seperti aplikasi biasa: ada ikonnya sendiri, terbuka tanpa bilah alamat browser, dan terasa lebih cepat dibuka dibanding lewat browser biasa.

## Desktop (Chrome / Edge)

1. Buka dashboard di browser Chrome atau Edge.
2. Cari ikon instal di bilah alamat, di sebelah kanan (ikon layar dengan tanda panah ke bawah).
3. Klik ikon itu, lalu klik **Install**.
4. Kalau ikon itu tidak terlihat, buka menu titik tiga (⋮) di pojok kanan atas, cari **Instal Executive Dashboard...** atau **Aplikasi > Instal situs ini sebagai aplikasi**.
5. Dashboard akan terbuka di jendela sendiri, terpisah dari browser, dan muncul di daftar aplikasi komputer Anda.

## Android (Chrome)

1. Buka dashboard di Chrome.
2. Biasanya akan muncul notifikasi otomatis di bagian bawah layar, "Tambahkan Executive Dashboard ke layar utama" — ketuk **Instal** atau **Tambahkan**.
3. Kalau notifikasi itu tidak muncul, ketuk menu titik tiga (⋮) di pojok kanan atas, lalu pilih **Instal aplikasi** atau **Tambahkan ke layar Utama**.
4. Ikon dashboard akan muncul di layar utama HP Anda seperti aplikasi lain.

## iPhone / iPad (Safari)

Instalasi ini **cuma bisa lewat Safari** — Chrome atau browser lain di iPhone tidak bisa memasang aplikasi web.

1. Buka dashboard di Safari.
2. Ketuk ikon **Bagikan** (kotak dengan panah ke atas), biasanya ada di bagian bawah layar.
3. Gulir ke bawah pada daftar pilihan, ketuk **Tambah ke Layar Utama**.
4. Ketuk **Tambah** di pojok kanan atas untuk konfirmasi.
5. Ikon dashboard akan muncul di layar utama iPhone/iPad Anda.

## Kenapa perlu dipasang

- Buka dashboard langsung dari ikon, tanpa perlu mengetik alamat atau mencari tab browser.
- Tampilan lebih lega — tanpa bilah alamat dan tombol navigasi browser.
- Terasa lebih responsif saat dibuka dari HP, termasuk saat scroll dan buka menu.
