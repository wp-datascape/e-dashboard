Intercompany transactions are transactions between companies within the same group (for example, one company selling to another company under the same holding). These transactions can make KPI numbers look bigger than actual sales performance to external customers.

## Steps

1. Open any page that has a filter bar (Dashboard, Growth, Retention, Value, Customer, Product, Transaction, and others).
2. Find the **Exclude Intercompany** toggle in the filter bar.
3. Turn it on to hide intercompany transactions from the calculation.
4. Every card, chart, and table on that page recalculates automatically without intercompany transactions.

## Note

This setting applies per page, not as a global setting for the whole dashboard — you'll need to turn it on again on other pages if you want it applied consistently.
